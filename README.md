# Avomadoh Painting Services Ghana 🇬🇭
> Master House & Room Painters · Residential, Storey Buildings & POP Ceilings · Accra & Kumasi, Ghana

A professional web application and scheduling platform for **Avomadoh Painting Services**, showcasing real completed painting projects across Ghana, an instant cost estimator in Ghana Cedis (`GH₵`), an integrated walkthrough booking system, and a live homeowner project tracker.

---

## 🌟 Key Features

### 1. Real Ghana Projects Showcase
- **Spacious Hallway POP Ceilings & Decorative Arches** (*Warm Sand Beige with pure white arches*)
- **Modern Two-Storey Storey Building Full Exterior** (*Coral WeatherShield Sky Blue with golden balcony pillars*)
- **Contemporary Bungalow with Orange Accent Pillars & Perimeter Wall** (*Soft Lilac with Tangerine columns*)
- **Executive Gated Bungalow with Stone Clad Entrance** (*Terracotta Peach with protective dark base skirting*)

### 2. Instant Cost Estimator in Ghana Cedis (GH₵)
- Scope selector: Interior rooms, full exterior building, decorative pillars/arches, or compound fence walls.
- Room count and square footage calculation with live Cedis estimates.
- Plaster prep condition selector (cured plaster vs hairline cracks vs fresh concrete rendering).
- Add-ons for POP ceilings and decorative arches.
- Real-time estimated range in **Ghana Cedis (GH₵)** and estimated on-site days.

### 3. Integrated On-Site Walkthrough Scheduler
- Select convenient date and time window for free in-person property measurement.
- Direct sync to **Google Calendar** and downloadable **`.ics` calendar invite** (Apple Calendar & Outlook).
- Direct **WhatsApp** integration for fast customer communication.

### 4. Live Homeowner Paint Job Tracker
- Enter Job Code (e.g., `JOB-2026-4912`) to follow all 8 phases:
  1. *Walkthrough & Laser Measurement*
  2. *Itemized Quote Approved*
  3. *Colors & Test Swatches Finalized*
  4. *Tile Protection & POP Joint Skimming*
  5. *Anti-Peeling Sealer Primer*
  6. *Double Topcoats & Freehand Cut-In Lines*
  7. *Owner Walkthrough with Work Lights*
  8. *Tile Cleaning & 2-Year Weather Warranty Handover*

### 5. Painter Back-Office Dashboard
- Private contractor portal to review incoming walkthrough appointments.
- Advance active painting projects across phases.
- Manage weekly crew booking capacity.

## 🚀 Running Locally

1. **Clone repository:**
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
